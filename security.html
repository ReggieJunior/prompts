Free · built into Claude Code

Find the hole before your users do

Claude Code has a security review built in, made by Anthropic. It reads your changes like a hacker: keys left in the code, pages anyone can open, payments nobody checks.

Tap Copy, then paste.

1
Run it

Open Claude Code in your project (on the branch with your changes) and type:

/security-review
2
Fix what it finds

Then paste this in the same chat:

Fix every finding from the security review, most severe first. Make the smallest change that fixes each one, then run /security-review again until nothing is left.
3
Make it automatic

Optional: review every pull request on GitHub. Add this file as .github/workflows/security.yml (it needs a CLAUDE_API_KEY secret):

name: Security Review
permissions:
  pull-requests: write
  contents: read
on:
  pull_request:
jobs:
  security:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          ref: ${{ github.event.pull_request.head.sha || github.sha }}
          fetch-depth: 2
      - uses: anthropics/claude-code-security-review@main
        with:
          comment-pr: true
          claude-api-key: ${{ secrets.CLAUDE_API_KEY }}
